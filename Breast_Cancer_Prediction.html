Week 6 Final Project - Breast Cancer Prediction using Machine Learning¶

Subject: Artificial Intelligence Internship | Project type: Disease Prediction (Classification)

Task 1: Project Selection and Problem Statement¶

Project Title: Breast Cancer Prediction using Machine Learning

Problem Statement: Doctors have to decide whether a tumour found in a patient is malignant (cancerous) or benign (not cancerous). This is normally done by studying cell measurements taken from a biopsy. Doing this by hand is slow and can differ from one doctor to another. The problem is to build a model that looks at the measurements of a tumour and predicts whether it is malignant or benign.

Objective:

  • Clean and understand the Breast Cancer Wisconsin dataset
  • Find which tumour measurements are most related to cancer
  • Train a classification model and test it on unseen data
  • Evaluate the model using accuracy, precision, recall and a confusion matrix

Why AI/ML is suitable: The dataset has 30 numeric measurements for each patient. It is hard for a person to look at all 30 numbers together, but a machine learning model can learn the pattern between the measurements and the diagnosis from past (labelled) cases and then use it on new cases. This is a supervised classification problem because we already know the correct answer for every record.

Expected Outcome: A model that predicts malignant / benign with high accuracy (above 95%) and very few wrong predictions, especially very few missed cancer cases.

Real-world Application: Such a model can work as a second opinion tool for doctors and help in early screening of breast cancer. Early detection improves the chances of treatment. (It supports the doctor; it does not replace the doctor.)

Task 2: Data Collection and Data Preprocessing¶

Dataset: Breast Cancer Wisconsin (Diagnostic) dataset. It is available inside the scikit-learn library (and on the UCI Machine Learning Repository). It has 569 patient records and 30 features that describe the cell nucleus (radius, texture, area, smoothness etc.) plus the diagnosis.

Step 4: Select the algorithm and train the model¶

I selected Logistic Regression. Reasons:

  1. It is made for binary classification (malignant / benign) and gives a probability for each patient.
  2. Many features here are strongly related to the target in an almost linear way (as seen in the heatmap and scatter plot), which suits Logistic Regression.
  3. It is simple, fast, and easy to explain. In medical problems, being able to explain the model is important.
  4. The coefficients show which features push the prediction towards malignant or benign.

To confirm my choice, I also trained 3 other models (Decision Tree, KNN, Random Forest) and compared them.

Conclusion¶

  • I cleaned the Breast Cancer Wisconsin dataset (569 rows, 30 features). It had no missing values and no duplicates.
  • EDA showed that malignant tumours are bigger and have more concave edges than benign ones.
  • I trained a Logistic Regression model on 80% of the data and tested it on the remaining 20%.
  • The model was compared with Decision Tree, KNN and Random Forest and gave the best results.
  • The model reached an accuracy of about 98.2% on the test set, with matching precision and recall of about 98.6%.
